# Base

日常必装的常用技能——环境、依赖、提交信息、技能管理，开箱即用。

- **[browser-tools](./browser-tools/SKILL.md)** — 基于 Chrome DevTools Protocol 的交互式浏览器自动化：打开页面、点击、截图、提取内容。
- **[env-info](./env-info/SKILL.md)** — 开发环境配置参考：工具路径、版本、包管理器偏好（pnpm 优于 npm/yarn，uv 优于 pip）。
- **[git-commit-msg](./git-commit-msg/SKILL.md)** — 按 Angular Conventional Commits 规范生成提交信息：`type(scope): subject` + body/footer。
- **[skill-creator](./skill-creator/SKILL.md)** — 创建、修改、优化 skill，并运行 eval 评测性能与触发准确性。
- **[skill-deps](./skill-deps/SKILL.md)** — 依赖管理规范：skill 安装 Python（uv/venv）或 Node（pnpm 本地）依赖的规则。
- **[skill-vetter](./skill-vetter/SKILL.md)** — 安全优先的 skill 审查：安装前审计来源、权限与风险。
