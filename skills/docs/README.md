# Docs

Office 文档（Word / PDF / PPT / Excel）的创建、读取、编辑与分析。

- **[docx](./docx/SKILL.md)** — Word 文档全流程：创建、读取、编辑、提取重组内容、插入替换图片、查找替换、修订与批注。
- **[pdf](./pdf/SKILL.md)** — PDF 全流程：读取提取、合并拆分、旋转、加水印、创建、表单填写、加解密、OCR。
- **[pptx](./pptx/SKILL.md)** — PPT 全流程：创建演示文稿、读取解析文本、编辑修改、合并拆分、模板与备注。
- **[xlsx](./xlsx/SKILL.md)** — 电子表格全流程：读写编辑 .xlsx/.xlsm/.csv/.tsv、公式计算、格式化、图表、数据清洗。
